# Project Map

이 문서는 프로젝트의 활성 기능 인벤토리다. 새 기능을 만들기 전 여기서 동일·유사 기능 존재 여부를 확인한다.

- **갱신 주체**: `project-cleanup` 스킬 또는 기능 추가 시 PR에서 직접
- **버려진 기능은 여기 두지 않는다**. `docs/decisions/`에 abandoned ADR로 기록한다.
